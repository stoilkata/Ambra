# Ambra

Marketing site for the Ambra Android app. Vite + React + TypeScript + MUI, dark navy.

Live: [ambra.ong](https://ambra.ong)

```bash
npm install
npm run dev
```

## Hosting

GitHub Pages, custom domain `ambra.ong`. DNS is at Cloudflare (registrar).

GitHub Actions publishes `main`. The custom domain is set in **Settings → Pages**, not by the `public/CNAME` file (Actions ignores that file). Keep the file anyway so the domain is documented in the repo.
